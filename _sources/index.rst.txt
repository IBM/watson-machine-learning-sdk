The ibm-watson-machine-learning library
=======================================

.. warning::

    Please be advised that the ``ibm_watson_machine_learning`` package is currently in maintenance mode,
    starting with the IBM Cloud Pak for Data 5.0.x release.
    We recommend migrating to the ``ibm_watsonx_ai`` package, which offers enhanced functionalities and performance.
    Detailed migration guides are available `here <https://ibm.github.io/watsonx-ai-python-sdk/migration.html>`_.

----

The ``ibm-watson-machine-learning`` Python library allows you to work with IBM Watson Machine Learning services.
You can train, store, and deploy your models, score them using APIs, and finally integrate them with your application
development.

For supported product offerings refer to :ref:`Product Offerings<product-offerings>` section.
